Features

Eleven things, all shipped.

Nothing below is planned or coming soon. It is in the app you download today.

01

Chat

Text chat with attachments — a camera shot, a photo or a file — and voice input. Ask in the language you think in and the answer comes back in the same one.

02

Vibe — live voice

A real-time two-way spoken conversation with mute and speaker controls. It runs as a foreground session, so the screen can lock while you talk.

03

22 Indian languages

Answers in any of 22 Indian languages, including the scheduled languages of India. Romanized Kannada is understood as Kannada, not as English.

04

Memory

Long-term memory you can review, edit or delete, kept separate from your profile. Nothing is remembered without a place where you can see it.

05

Authenticator

Add accounts by QR code, setup URI or setup key, and get TOTP codes beside the chat. Back up to a printable recovery PDF; deleted accounts sit in Trash for 30 days.

06

Plugins

Connect Gmail, Zoho Mail and GitHub. A question about your mail or your code gets an answer from the account, and a write needs your approval every time.

07

Security

App lock, PIN, biometric unlock and auto-lock when you leave, separate from the phone's own lock. Screens that hold codes are protected from screenshots.

08

Cloud sync

One account across devices: a conversation started on the phone continues in the browser, at the message you stopped at.

09

Sensitive-info masking

Aadhaar, PAN, IFSC, UPI, card numbers, phone numbers and email addresses are masked before the model ever sees them. The reply never repeats a full number.

10

Code running

Snippets run in a sandbox with time and memory limits, no network and no access to anyone else's data. A failing snippet returns the error, not a guess.

11

Built for India

Indian context is the starting point rather than an add-on: languages, identifiers and the way people actually type on a phone.

Languages
