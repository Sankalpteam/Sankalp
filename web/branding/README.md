# Web branding

The mark is one image: `../assets/mark.png`, the supplied artwork with its pale background
removed so it sits on the white header, on the lilac account tile and on the auth screens
without a square behind it. It is generated by `scripts/brand_assets.py` from
`branding/sankalp-mark.png`, along with every `assets/icon-*.png`, `favicon.ico` and
`assets/og-image.png`.

- `shared/branding.js` — replaces `.brand-mark`, `.auth-mark`, `.about-mark`, `.token-icon`
  and `.chat-logo` with that image. It does not draw the logo.
- Favicons are static `<link>` tags in `index.html`. Nothing is drawn at runtime, because a
  crawler reads the HTML it is served and never runs the script.

New UI must keep using the shared `branding.js` wiring. Do not add a screen-specific logo
file, and do not redraw the mark as inline SVG.
