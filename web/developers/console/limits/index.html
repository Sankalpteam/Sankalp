When a limit is reached

429 Too Many Requestswith a body that says which limit was hit and when to retry
Retry-Afterseconds to wait before sending again
X-RateLimit-Limitthe limit that applies to this key
X-RateLimit-Remainingwhat is left in the current window
X-RateLimit-Resetwhen the window resets, in seconds

Sample figures until the gateway counts real ones. The limits belong to the key, not to the account, so one runaway script cannot stop every other key - and the response headers above are what a client needs to back off on its own instead of hammering and failing.
