The first call

One endpoint, OpenAI-shaped. The response says which model answered it and how many tokens were billed, so the bill and the answer always agree.

# one endpoint, OpenAI-shaped
curl https://api.sankalp.in/v1/chat/completions \
  -H "Authorization: Bearer sk-live-..." \
  -H "Content-Type: application/json" \
  -d '{
    "model": "sankalp-1",
    "messages": [{"role":"user","content":"hi"}]
  }'

What it costs

Input tokens are charged at a fifth of output tokens, on both paths. Nothing is charged for a request that fails.
